## ☁️ How to Deploy to Cloudflare Pages (100% Free & Fast)

1. Open [Cloudflare Dashboard](https://dash.cloudflare.com/).
2. Go to **Compute (Workers & Pages)** > **Create application** > **Pages** > **Upload assets**.
3. Set your project name (e.g. `noreen-portfolio`).
4. Drag & drop the `noreen_portfolio` folder.
5. Click **Deploy site**. Your portfolio is live across the globe!
